1 · The write path

Three hops, one wait

  1. The browser sends a write to the API.
  2. The API queues it and answers 202 at once.
  3. A worker drains the queue into the database, in batches.

Start with the browser: one request, nothing else yet.

The point of the slide: the API answers before the write is stored.

Batches keep the database's load flat; ask who reads the queue's depth.
